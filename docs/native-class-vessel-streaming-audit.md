# Streaming the native-class vessel audit

The [new auditor](../tools/audit_native_class_vessel_streaming.py) reconstructs
the complete schema-7 native-class proposal, including its schema-8 wall-envelope
variant, in bounded batches. It reuses the already validated class, axis and
Gaussian-component decoder. It changes no physical proposal, estimator or
assembly kernel and has no launch or convergence-gate authority.

Each saved pose is still scored under the full normalized mixture. The saved
world density and conditional generation trace retain their distinct coordinate
checks. Schema 8 must explicitly identify the class law as its underlying
schema; schema 7 rejects hidden wall-envelope metadata. Compiled native bytes,
their original definition and the complete physical-shape correspondence are
authenticated. The synthetic observer adapter remains restricted to small
fixtures and cannot audit proteins.

The row/journal reader checks the original global indices before temporary
batch copies are numbered from zero for the existing reference functions.
Summed counters, fixed chart metadata, maximum reconstruction errors and outer
branch counts are checked again against the original population denominator.
Invalid poses contribute explicit zeros. Independent atomic wall/core/exclusion
checks supply one `geometry.jsonl` record for every attempt; physical native
classification remains the later partition's responsibility.

On success the auditor writes `analysis.json`, `status.json`, `geometry.jsonl`,
an archived local source closure and `freeze.json`. Their hashes connect the
input population, attempt journal, executable and embedded source bundle.
On failure, completed geometry records and failed status remain; no successful
analysis or freeze is manufactured. The supplied binary is authenticated, never
executed by the auditor. An eventual controller must separately pin the runtime
and authenticate its resource and execution receipts.

Memory comprises one batch of full density traces, fixed model/shape/source
buffers, and two scalar top-one-percent heaps per reported region. Those heaps
grow as `ceil(N/100)`; this is not constant memory in population size. The
allowed batch size is 1–1,024. Two-cloud arithmetic means, importance moments
and signed residual pose variance reuse the existing streaming reducers.

## Completed bounded validation, 2026-10-06

[Thirteen synthetic tests](../tools/test_audit_native_class_vessel_streaming.py)
passed in 2.088 CPU seconds. They cover schema and completion failures,
duplicate/missing journals, partial final batches, counter and chart-identity
checks, explicit invalid zeros, eager-versus-streaming importance/paired-noise
moments, binary tampering, preserved failure prefixes and the completed
geometry/status/freeze contract. These controls mock the expensive geometry
decoder and make no physical geometry queries.

A separate saved-fixture control used the first eight existing depletion rows
from each of the previously validated schema-7 and schema-8 sphere fixtures.
Each was reconstructed once by the complete reference helper and once in
streaming batches of 3, 3 and 2: **16 unique saved poses, 32 density pose
reconstructions**, 0.140 CPU seconds. Density diagnostics agreed exactly in both
controls. Importance and paired-noise moments agreed within the fixed numerical
tolerance, including five invalid zeros in the schema-7 subset. The test reused
archived region flags for moment reduction; it made no new physical core/contact
queries or full native-classification calls. It generated no poses or clouds.
Several interval axes/channels can be reconstructed per pose, so the count of
32 is not a count of primitive atom operations.

Both jobs ran sequentially with one thread and 2 GiB limits. Synthetic limits
were 20 CPU/60 wall seconds; fixture limits were 10 CPU/30 wall seconds. The
completed host check found the controller identity and both owned child process
groups absent. Metadata-only attempt01 was superseded before dispatch when an
explicit eager-moment control was added; it contains no test execution. No failed
scientific allocation was rerun.

## Integration still required

**Subsequent integration:** the class schema is now registered in the partition
and stage reader, with twenty passing integration controls. The baseline
auditor now supports schema 8, and a new immutable 116-component protein
preparation has been created and validated. A separate regional-prerequisites
adapter preserves the unresolved scientific evidence. See the
[integration record](native-class-vessel-integration.md). Scientific admission
and the reviewed dispatcher still remain; no full-vessel protein job has been
launched. The following paragraph records the state when this auditor was first
validated.

The new audit schema is deliberately **not yet registered** in
`partition_vessel_streaming.py` or `analyze_streaming_vessel_stage.py`. A reviewed
adapter must bind its geometry records, source closure and compiled-native
provenance before either tool consumes it. The pure vessel schema-8 baseline is
outside this implementation; the existing baseline auditor still requires
schema 4. A new immutable guide/executable preparation and an admission adapter
for the completed regional sensitivity and matching SMC evidence also remain.
The [physical status review](autonomous-physical-evidence-status.md) records
these gaps. No protein population or full-vessel campaign was launched.
