# Saved-candidate coverage before absolute contact weights

This check asks whether the independent proposals already generated by the
fixed-context pilot cover the secondary-contact arrangement that its accepted
trajectories failed to exchange. It changes no production move or physical
measure. The system has one mobile tetramer and 263 fixed spectators from a
historical 500 μM configuration, with depletant radius 1.5 Å and activity
0.035 Å⁻³. It is not the all-mobile assembly endpoint near 106.8 μM.

The [importance argument](context-candidate-importance.md) establishes that
the zero-correlation global candidates have the independent density
`Q = 0.5 U + 0.5 G`, in translation volume times normalized rotational Haar
measure. Local proposals and correlated transport candidates are outside this
bank. Original and context-prior arms share seeds and remain paired across
eight distinct start/stream populations per arm.

## Completed result

**The bank misses the saved source secondary-contact region in every population.**
All sixteen geometry jobs completed, preserving 36,864 proposals and the sixteen
source checks. The corrected independent audit passed all 143,372 scalar checks
and its complete 512-pose density/geometry panel. The largest scalar discrepancy
was 0.0000166 times its declared tolerance. No new poses or Poisson clouds were
generated.

Complete source-token inclusion also has **zero hits across all valid candidates**,
including Other contact. Thus the failure is not an artifact of requiring exactly
the two A neighbors. The largest intersection anywhere is only 3/16 source tokens
under the original prior and 4/16 under the context prior. These counts include warmup and both accepted and rejected
proposals; they are not equilibrium occupancies. The context prior increases
contact proposals from 103 to 613 but does not cover the strongly retained source
patch arrangement.

The geometry pass used 284.814 CPU seconds and 121.645 wall seconds with four
workers. The independent audit used 9.893 CPU seconds. All jobs drained. The
figure's bound uncertainty is averaged over hard-valid candidates, including
unbound ones; it is not a measured free-energy difference. Hard-only full-domain
volume sums are available in the report, but cannot resolve depletion weights.

Two complete clouds at intensity 64z would require about **199.88 million raw
points in expectation** for this bank (23.34 million original, 176.54 million
context). No such allocation is being made: reducing auxiliary-cloud noise cannot
recover a missing pose region. Zero hits provide no bound on that region's physical
mass. The result supports improving pose coverage before further absolute-weight
work on this bank; it does not support finite-system instability.

## Implementation

[`prepare_context_candidate_bank.py`](../tools/prepare_context_candidate_bank.py)
authenticates the completed physical and observer receipts and extracts every
one of the 16 × 2,304 global candidates. All 36,864 proposals remain, including
4,096 warmup candidates and every rejection. Extraction performs no geometry
queries and generates neither poses nor depletant clouds.

The separate Rust
[`context_candidate_bank_preflight`](../examples/context_candidate_bank_preflight.rs)
reconstructs the complete density at every saved pose, checks the original
hard-core and atomic-wall verdicts, classifies all valid candidates, and records
deterministic overlap-volume bounds. Density evaluation uses the actual map
and reciprocal branches, not a Gaussian fitted to inverse component centers.
The future absolute mass contribution would be `mean(W)/Q`; adding another
Jacobian would double-count the coordinate transformation.

The helper's atom-patch BVH preserves the strict leaf overlap predicate.
Conservative body bounds prune distant fixed particles from overlap-envelope
construction. Synthetic tests compare these shortcuts against unpruned geometry.
Ordinary guarded floating-point predicates remain an implementation obligation;
the volume bounds are not a formal interval-arithmetic certificate.

The independent Python
[`audit_context_candidate_bank.py`](../tools/audit_context_candidate_bank.py)
checks every scalar row and reconstructs density and geometry on a fixed panel
of 512 poses: ordinals 0, 72, …, 2232 from each chain. It includes invalid poses
without replacements. Six extraction tests, thirteen Rust tests and ten Python
audit tests passed before the protein preflight. The isolated build leaves the
production executable unchanged.

The first independent-audit attempt stopped before any panel geometry: its
manifest omitted direct bindings for the original shape/context/source paths,
which the Rust preflight had authenticated through the invocation configuration.
The failure and its drained process receipt are retained in
`results/context-candidate-bank-independent-audit-20261005`. The correction adds
those expected hashes to a fresh audit manifest; it changes no candidate,
classifier, density, test panel, or completed geometry calculation.

## Fixed regions and coverage interpretation

The source reference is the complete set **T of 16 secondary-neighbor patch
tokens in the saved initial pose**, agreed upon by all twelve initial observer
records. It is not a selection of tokens chosen because production trajectories
failed to visit them. Each token labels the contacting member/octant patches on
mobile body 77 and fixed body 217; token count is neither contact area nor energy.

All valid candidates belong to exactly one of:

- Neighbor set A = {16, 217}, subdivided by `|P217 ∩ T|/16` into
  [0, .25), [.25, .5), [.5, .75), [.75, 1), and {1}.
- Neighbor set B = {16, 56}.
- Every other contacted pose.
- Unbound poses.

Hard-invalid candidates contribute zero and remain in the denominator. The
complete-T category permits extra patch tokens. Complete-T hits are also counted
outside A, so an additional neighbor cannot silently hide a recovered source
patch arrangement.

These are source-informed coverage diagnostics, not native classifiers. Zero
hits cannot establish zero physical mass or exclude all equivalent/native
arrangements. Nonzero hits do not establish sufficient importance ESS. Hard-only
`1/Q` sums and `z × volume` bounds are reported separately from depletion weights.

## Allocation and admission

The frozen geometry allocation is sixteen jobs with four simultaneous workers,
one thread each, and per-job ceilings of 600 CPU seconds, 1,200 wall seconds and
8 GiB. Every chain includes its 2,304 candidates and one source-reference audit.
Failures drain the allocation and preserve begun prefixes; no candidates are
replaced. The subsequent independent panel has ceilings of 300 CPU seconds,
600 wall seconds and 4 GiB, and requires all sixteen preflights to complete.

There are **no Poisson clouds in this allocation**. At two clouds per valid pose
and auxiliary intensity 64z, the expected raw-point allocation would be
`4.48 × sum(uncertain overlap-envelope volume)`. This is an expectation, not a
bound on realized Poisson counts. It measures prospective cost without pretending
that more cloud samples would fix missing pose coverage.

Any later absolute-weight allocation needs its own frozen cloud seeds, complete
denominators and bounded failure handling. Even converged conditional contact
weights would leave the finite-system assembly question open.

## Minimal fallback if coverage fails

A fresh, frozen independent proposal
`q* = 0.5 U + 0.25 G_context + 0.25 g_source` could add one normalized Cayley
Gaussian centered on the certified source pose. Its fixed covariance must be
declared before new draws; no feasibility retries or conditioning on accepted
draws are allowed. Existing decode and checked-density APIs make its physical
density tractable. Score every candidate under the complete mixture, including
all reciprocal branches, and use independent absolute clouds in `mean(W)/q*`.
This would test a source-informed conditional pocket, not discover that pocket
without prior information.

Width sensitivity and independent populations would still be needed: the
immediate source neighborhood need not cover every configuration in the T region.
The existing 50% uniform component supplies full support but no useful bound on
the physical weight of unseen narrow pockets. The full complement must stay in
the calculation. A guide chosen after observing this bank requires fresh
evaluation draws; these saved proposals do not become an independent test set
for that choice.

The existing two-contact Gaussian fusion offers a larger follow-up. It produces
normalized proposal charts approximating the joint contact constraints. It is
not an exact normalized product of two nonlinear physical pose densities. Its
full mixture density, rather than that hypothetical product, must appear in
importance weights or reversible acceptance. Neither fallback is allocated here.
